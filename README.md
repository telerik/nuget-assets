# NuGet Assets

This repository contains assets (images, banners, icons, etc.) used by [Telerik](https://www.telerik.com/) products on [NuGet.org](https://www.nuget.org/).

## Structure

Assets are organized by product. Each product has its own folder containing the relevant files.

| Folder | Product |
|--------|---------|
| `maui/` | Telerik UI for .NET MAUI |

## Usage

Assets in this repository are referenced directly from NuGet package metadata. Links should point to the raw file URLs on the default branch.

## Contributing

When adding assets for a new product, create a dedicated folder using the product's short name and place all related files inside it.
